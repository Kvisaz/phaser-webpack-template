# Code and Phaser Tricks

## создание UI на только что добавленной  сцене
- overlay scenes: создание UI на только что добавленной дочерней сцене может падать (`queueDepthSort` null), если сцена не успела пройти boot/create. Обход: дождаться `Phaser.Scenes.Events.CREATE` или дать небольшой timeout перед конструированием/показом диалога.

## Phaser.Container удобен как аналог div
можно оборачивать один элемент (например, кнопку) и выравнивать контейнер, не трогая внутреннюю логику ребенка.

## Переопределение destroy у любого Phaser.GameObjects.GameObject
- Всегда вызывай `super.destroy()` в конце, иначе Phaser продолжит дергать destroy цепочкой (события/child сцены) и можно получить циклы/висяки при смене сцен.
