# DragDrop (общий drag&drop для карточных игр)

Этот модуль предоставляет минималистичный drag&drop для Phaser GameObjects.
Он специально сделан максимально общим, поэтому часть нюансов (например, размеры зон дропа) должны решаться на стороне конкретной игры.

## Как работает DragDrop

`DragDrop` подключается к списку `draggables` и слушает события Phaser:
- `GAMEOBJECT_DRAG_START` — начало взаимодействия (в нашем коде это фактически "pointer down").
- `GAMEOBJECT_DRAG` — перемещение объекта(ов).
- `GAMEOBJECT_DRAG_END` — завершение (в нашем коде это "drag end / pointer up").

Дальше логика такая:
1) если объект не draggable (`isDraggable` вернул false) — drag не стартует;
2) если drag не стартовал — `onDragObjectPointerUp` считается кликом;
3) если drag стартовал — считаем смещение от стартовой позиции:
   - меньше порога (`dragThreshold`) => считаем, что это клик;
   - больше порога => считаем, что это дроп (пытаемся найти dropZone).

## Как выбирается dropZone

Выбор зоны дропа происходит через `findSimpleMaxOverlap`:
- берём `getBounds()` у перетаскиваемого объекта
- берём `getBounds()` у каждой `dropZone`
- выбираем dropZone с максимальной площадью пересечения (overlap area)

## Контракт: dropZones должны иметь корректный getBounds()

`DragDrop` не знает ничего про "стопки", "колонки" и "цепочки карт".
Он оперирует только прямоугольниками (`getBounds()`), поэтому:

- `dropZones` должны возвращать bounds по реальной интерактивной области;
- если у dropZone bounds "маленький" (например, только placeholder одной карты), то дроп по визуально очевидной цели может не распознаться.

### Типовая ошибка на карточных играх

В пасьянсах колонка может быть высокой (карты разложены вниз), а placeholder (`cardPlace`) остаётся размером с одну карту.
Игрок отпускает карту "на колонку", но на самом деле пересечение с placeholder = 0, поэтому:
- `dropZone` не найден
- дроп считается невалидным
- карта/цепочка "откатывается" (или трясётся)

### Способ решения (рекомендованный)

Сделать bounds стопки (dropZone) высотой по текущему содержимому.
Самый простой вариант: объединить bounds placeholder и верхней карты.

Пример (Spider):

```ts
getBounds(): Phaser.Geom.Rectangle {
  const baseBounds = this.cardPlace.getBounds();

  const topCardBounds = this.topCard?.getBounds();
  if (!topCardBounds) return baseBounds;

  return Phaser.Geom.Rectangle.Union(baseBounds, topCardBounds);
}
```

Эта логика остаётся внутри конкретной реализации стека и не требует правок `DragDrop`.

### Альтернативы (если union недостаточно)

- Делать отдельный `Phaser.GameObjects.Zone` нужного размера (визуально можно держать прозрачным) и использовать его как dropZone.
- Делать отдельную сущность "DropZone для колонки", которая сама считает bounds по текущей высоте/ширине колонки.

## Нюанс: клик vs "короткий драг"

`DragDrop` использует порог `dragThreshold`, чтобы отличить клик от дропа.
Если порог слишком большой, игрок может пытаться дропнуть, но система воспримет это как клик.

Рекомендация:
- не чинить это глобально в `DragDrop` (это легко ломает другие игры),
- настраивать `dragThreshold` в конкретной игре только если есть реальная проблема и после ручной проверки.
