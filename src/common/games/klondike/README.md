# Компонент KlondikeView - Пасьянс "Косынка"

## Общее описание

Компонент `KlondikeView` представляет собой основной класс для реализации пасьянса "Косынка" (Klondike Solitaire). Он управляет игровой логикой, обработкой пользовательского ввода, анимациями и состоянием игры.


## Подсказка vs автоход

- Автоход (клик по карте) идёт через `GameReactionsMapper.mapUserActionToMove` и выполняется сразу; стейт для этого не нужен.
- Подсказка выбирает один "лучший" вариант через `tricks.getHintCard()` и кладёт его в `hintCombo` в стейте.
- Валидных автоходов может быть несколько одновременно, а подсказка хранит только один выбранный вариант, поэтому синхрона 1:1 нет.


## Архитектура компонента

### Основные зависимости
- `IKlondikeConfig` - конфигурация игры
- `IKlondikeStackMap` - карта стопок карт (колода, рабочие стопки, целевые стопки)
- `IKlondikeCard` - представление карты
- `IKlondikeGameMaster` - игровой мастер, определяющий доступные ходы
- `IStatelessKlondikeAnimator` - аниматор для визуальных эффектов

### Структура класса

#### Основные свойства:
- `state` - наблюдаемое состояние игры с информацией о счете, истории ходов и текущем шаге
- `gameMover` - движок, выполняющий ходы на игровом поле
- `klondikeRules` - правила игры Косынка
- `tricks` - специальные игровые трюки и подсказки
- `scorer` - система оценки ходов (использует русский стиль подсчета очков)
- `playerMoveHistory` - история ходов для возможности отмены

#### Основные методы:

**Конструктор**
- Инициализирует все компоненты игры
- Раздает карты из колоды в рабочие стопки
- Подписывается на события пользователя и игры

**Обработка пользовательского ввода**
- `addUserInput()` - добавляет обработку низкоуровневого ввода (клик, перетаскивание)
- `addHighLevelUserInput()` - преобразует события в игровые действия
- `onInGameUserInput()` - обработка игровых действий (клик по карте, сброс карты)
- `onOutGameUserInput()` - обработка внешних действий (отмена, подсказки, магия)

**Игровые действия**
- `runMove()` - выполнение хода с начислением очков и обновлением истории
- `undoLastMove()` - отмена последнего хода
- `onHint()` - показ подсказки
- `onVision()` - показ скрытых карт
- `onMagic()` - выполнение магического хода

**Обновление состояния**
- `updateLiveStateCombos()` - обновление комбинаций для подсказок и трюков
- `setStep()` - изменение текущего состояния игры (idle/animation)

## Работа с событиями

Компонент использует систему событий для взаимодействия:
- `userEvents` - события от пользователя (клики, перетаскивание)
- `gameEvents` - события от игры (окончание раздачи, ходы, отмены)

## Игровые трюки и подсказки

- `magicCombo` - комбинации для автоматических ходов
- `hintCombo` - подсказки для следующего хода
- `visionCombo` - показ скрытых карт

## Система оценки

Используется `ClassicRussianScorer` для подсчета очков по русским правилам:
- Начисление очков за перемещение карт
- Учет специфических правил русской Косынки

## История ходов

- Все значимые ходы сохраняются в `playerMoveHistory`
- Возможность отмены последнего хода
- Поддержка отмены только определенных типов ходов (перемещение, взятие из колоды, повтор колоды, магия)

## Жизненный цикл компонента

1. **Инициализация**: создание всех зависимостей и раздача карт
2. **Обработка ввода**: ожидание действий пользователя
3. **Выполнение ходов**: обработка, анимация и обновление состояния
4. **Очистка**: при уничтожении компонента освобождаются все ресурсы

## Особенности реализации

- Используется дебаунсинг для оптимизации вычислений
- Поддержка асинхронных операций с анимациями
- Система подписок с автоматической очисткой
- Поддержка внешних систем ввода (не только пользовательский ввод)

Этот компонент полностью управляет игровым процессом Косынки, обеспечивая плавное взаимодействие, визуальную обратную связь и корректную игровую логику.
