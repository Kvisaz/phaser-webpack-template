## AnimaMover — что это

Коллекция утилит, которые **двигают объекты** (в отличие от `Anima`, который часто лишь “дрожит/пульсит” без смены позиции). Здесь логика перелётов, разлётов, дуг, гравитации и т.п. Входы — Phaser GameObjects, вызываться могут из UI/геймплея для эффектов лута, частиц, кнопок и т.д.

Не стопает предыдущую анимацию finishAnimation

## Рекомендации по коду

- Для **одношаговых** анимаций (один tween) можно завершать чужие твины через `finishAnimation(target)`, чтобы не накладывались эффекты.
- Для **цепочек** (одна анимация запускается после другой) избегайте `finishAnimation` в шагах, которые стартуют из `onComplete` предыдущего твина — это может вызвать рекурсивное `complete()` и переполнение стека. В цепочках лучше:
  - строить `timeline` (`scene.tweens.timeline()` / `createTimeline` + `add`) и добавлять шаги без `finishAnimation` между ними;
  - или вызывать следующий tween напрямую, не трогая предыдущий, если его `onComplete` уже завершился.
- Если нужна комбинация нескольких эффектов, отдайте предпочтение **timeline**: он сам управляет порядком/задержками и не конфликтует с завершением твинов.
- Оставляйте `finishAnimation` только там, где метод предполагается как самостоятельный “запуск анимации”, без последующих шагов цепочки.
