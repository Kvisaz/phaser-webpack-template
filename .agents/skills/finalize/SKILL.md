---
name: finalize
description: Use when preparing a completed change, feature, scene, or mini-game for final handoff.
---

Финализируй изменение без расширения scope.

Проверь:

1. Нет ли очевидных TODO в runtime-коде.
2. Не нарушены ли слои.
3. Нет ли лишних импортов.
4. Не раздуты ли сцены.
5. Нет ли event-подписок без cleanup.
6. Не изменен ли `changelog.md` без просьбы пользователя.
7. Все переносы файлов сделаны через `git mv`.

Не запускай typecheck, lint, build, браузер или dev server без прямой просьбы пользователя.

В финальном ответе укажи:
- измененные файлы
- что сделано
- какие проверки не запускались
- какую команду стоит запустить следующей
