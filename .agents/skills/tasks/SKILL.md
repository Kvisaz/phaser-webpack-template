Работай по `docs/ai/task.md`.

Создавай файл задачи только если пользователь явно просит создать задачу, план или оформить работу в task-файл.

Формат файла:

```txt
tasks/progress/YYYY-MM-DD.short-title.plan.md
```

Минимальная структура:

```md
# Название задачи

- оформлено: YYYY-MM-DD
- статус: план

Суть задачи -

## Анализ текущего состояния кода

## Вариант 1. Минимальный

## Вариант 2. Нормальный

## Риски
```

В обоих вариантах укажи:
- какие файлы изменятся
- почему
- примерный код или форму изменения

Минимальный вариант должен быть самым простым рабочим решением.

Нормальный вариант должен лучше соблюдать Layered Feature Folders из `docs/ai/layered-features.md`.

После создания плана не меняй production-код, пока пользователь не даст добро.

Если правила из `AGENTS.md` или старых заметок противоречат `docs/ai/task.md`, сообщи пользователю о конфликте перед созданием файла.
